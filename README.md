# Harris AI

Trợ lý ảo chạy local bằng Python + PyQt6, dùng Ollama làm model AI.

## Yêu cầu
- Python 3.10+
- [Ollama](https://ollama.com) đã cài và đang chạy

## Cài đặt
```bash
git clone https://github.com/<ten-cua-ban>/Harris_ai.git
cd Harris_ai
pip install -r requirements.txt
```

## Chạy
```bash
python main.py
```

## Ghi chú
- Tạo model tuỳ chỉnh từ `Modelfile`: `ollama create harris -f Modelfile`
